# RouteRescue – Alternative Journey Planner

## Overview
RouteRescue is a web-based transportation application that helps commuters find alternative road routes when they miss a bus.

## Technologies
- HTML, CSS and JavaScript
- Leaflet.js and OpenStreetMap
- Photon API for location search
- OSRM API for route calculation

## Features
- Location search and autocomplete
- Alternative road routes
- Interactive map
- Journey duration and route summary
- Sample bus schedules and delay simulation
- Responsive interface

## How to Run
1. Open the project in VS Code.
2. Run `index.html` using Live Server.
3. Enter your starting point and destination.
4. Click **Find Routes**.

## Future Scope
- Real-time GPS bus tracking
- Verified bus numbers and schedules
- Live arrival predictions
